## 10. Lessons

- **Loss does not predict task success** on this benchmark; only evaluation does.
- **The policies fail passively:** almost every failure is a time-out with the object never lifted.
- **The far side of the table is unsolved** by every checkpoint so far.
- **Uploads are the slow part of cloud training:** 6.6 GB took ~20 min from the workstation, while
  18 GB downloaded to Brev in ~1 min. Pull data from Hugging Face on the instance.
- **Scripting pitfalls hit today:**
  - `ssh` inside `bash -s` swallowing the script (use `ssh -n`).
  - A killed local `ssh` left its remote `rsync` running (two copies at once).
  - `pkill -f` over ssh matching its own command line.
  - The wrong override path `model.parallelism…` (correct: `model.config.parallelism…`).
- **No stop/start instances bill until deleted:** copy checkpoints back as they are saved and delete
  immediately.
